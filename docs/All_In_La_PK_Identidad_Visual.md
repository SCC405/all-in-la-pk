# Identidad visual y paleta de colores — All In La PK

## 1. Propósito

Este documento define la identidad visual base de **All In La PK**, una tienda en línea especializada en artículos de póker.

La propuesta busca transmitir una imagen de póker elegante, moderna y sobria, evitando una apariencia demasiado cargada o caricaturesca.

La identidad se construirá principalmente a partir de tonos oscuros, verde inspirado en los tapetes de póker y detalles dorados.

---

## 2. Concepto visual

La interfaz de All In La PK tendrá como base los siguientes conceptos:

- Elegancia.
- Póker.
- Casino.
- Sobriedad.
- Contraste.
- Apariencia premium.
- Facilidad de lectura.

La aplicación utilizará fondos oscuros, superficies en gris oscuro, verde como color principal y dorado como color de acento.

---

## 3. Paleta de colores principal

| Color | Código HEX | Uso principal |
|---|---|---|
| Negro carbón | `#0D0D0D` | Fondo principal de la aplicación |
| Gris oscuro | `#1C1C1C` | Tarjetas, paneles, formularios y superficies |
| Verde póker | `#0F5132` | Color principal de marca, botones y elementos activos |
| Verde oscuro | `#0A3622` | Navbar, footer y variaciones del color principal |
| Dorado | `#D4AF37` | Acentos, botones destacados y elementos premium |
| Rojo cartas | `#B3261E` | Alertas, errores y acciones de eliminación |
| Blanco humo | `#F5F5F5` | Texto principal |
| Gris claro | `#A7A7A7` | Texto secundario y elementos menos importantes |

---

## 4. Uso de cada color

### Negro carbón — `#0D0D0D`

Será el fondo principal de la aplicación.

Se utilizará en:
- Fondo general.
- Secciones principales.
- Páginas del catálogo.
- Fondo del carrito.
- Fondo del panel administrativo.

### Gris oscuro — `#1C1C1C`

Se utilizará como color de superficie.

Aplicaciones principales:
- Tarjetas de productos.
- Formularios.
- Paneles administrativos.
- Contenedores.
- Modales.
- Secciones internas.

### Verde póker — `#0F5132`

Será el color principal de identidad de All In La PK.

Se utilizará en:
- Botones principales.
- Elementos activos.
- Bordes destacados.
- Indicadores.
- Títulos secundarios.
- Filtros seleccionados.
- Acciones de edición.

### Verde oscuro — `#0A3622`

Funcionará como una variante más profunda del verde principal.

Se utilizará principalmente en:
- Navbar.
- Footer.
- Hover de botones verdes.
- Fondos secundarios.
- Elementos de navegación.

### Dorado — `#D4AF37`

Será el color de acento premium de la interfaz.

Se utilizará en:
- Botones destacados.
- Precio de productos seleccionados.
- Detalles de marca.
- Bordes decorativos.
- Iconos importantes.
- Estados activos.
- Elementos relacionados con promociones.

Debe utilizarse con moderación para mantener una apariencia elegante.

### Rojo cartas — `#B3261E`

Se utilizará únicamente en acciones o estados que requieran atención.

Ejemplos:
- Eliminar productos.
- Eliminar categorías.
- Mensajes de error.
- Alertas.
- Estados críticos.

### Blanco humo — `#F5F5F5`

Será el color principal de texto sobre fondos oscuros.

Se utilizará en:
- Títulos.
- Nombres de productos.
- Texto principal.
- Etiquetas importantes.
- Botones oscuros.

### Gris claro — `#A7A7A7`

Se utilizará para información secundaria.

Ejemplos:
- Descripciones.
- Textos auxiliares.
- Información de stock.
- Placeholders.
- Etiquetas secundarias.

## 16. Reglas visuales generales

1. Evitar fondos completamente blancos.
2. Mantener una interfaz principalmente oscura.
3. Utilizar verde como color principal.
4. Utilizar dorado como acento y no como color dominante.
5. Reservar el rojo para errores y acciones destructivas.
6. Mantener suficiente contraste entre texto y fondo.
7. Evitar utilizar demasiados colores adicionales.
8. Mantener consistencia entre catálogo, carrito y panel administrativo.
9. Utilizar los mismos estilos de botones en toda la aplicación.
10. Mantener una apariencia moderna relacionada con el mundo del póker.
